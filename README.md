## Utilisation des commande Git

`git status` = verifie les fichier modifié

`git add .` = ajoute les fichier pour le commit

`git commit -m "mon message"` = cree le commit avec un message

`git push` = envoi le code modifier sur le repo git distant

`git pull` = mais a jour le code local sur le pc a jours avec le distant code sur Git
